# Review Checklist

- [ ] Original task preserved in `task/raw.md`.
- [ ] Spec acceptance criteria are concrete enough to verify.
- [ ] Reproduction result is classified honestly.
- [ ] Changed files are scoped to the task.
- [ ] Eval results are present.
- [ ] Lens proof is present for browser workflows.
- [ ] PatchBrief, ChangeBucket, ShipCheck, and RunLedger reports exist.
- [ ] Handoff contains residual risks and reviewer notes.
- [ ] Client packet contains no secrets, raw cookies, passwords, or private customer data.
