# VideoOps Quality Review

Runs the independent Video Critic fixture contract. Deterministic ffprobe evidence precedes the ten-dimension review. The first fixture candidate contains a deliberate high-severity CTA contrast defect and returns schema-shaped FAIL/fix evidence; the revised candidate returns PASS. Three failed cycles stop instead of looping.

```bash
bin/run --fixture --workspace /absolute/project/path --run-id example
bin/run --fixture --workspace /absolute/project/path --run-id example --revision-count 1 --attempt 2
```

The fixture proves deterministic review structure. Production visual judgment still requires an approved multimodal or human reviewer.
